# YukiOshi Code brand assets

These are the original YukiOshi Code product logos supplied by the project owner. They are distinct from the parent-brand YukiOshi logos and should not be relabeled as those assets.

- `yukioshi-code-wordmark-light.png` — wide geometric snowflake wordmark for light backgrounds and repository/product headers.
- `yukioshi-code-emblem-dark.png` — square snowflake-and-code emblem composed for dark backgrounds.

Keep the original files intact. Any cropped, transparent, monochrome, favicon-sized, or otherwise derived variant should be added as a separately named asset rather than replacing these originals.

The terminal UI shows a traced version of `yukioshi-code-emblem-dark.png` (the emblem and the "YukiOshi" wordmark drawn with quadrant block characters). After changing that file, regenerate it with `python3 packages/tui/script/generate-logo.py` (requires Pillow).
